# Group-3-Medication-And-Vitamin-Logger
CSE215 Theory Project

A Medication and Vitamin Logger where each user lists their prescribed medicines and vitamins along with the schedule for each medication, along with a reminder alert to not miss any dose alongside statistics on adherence and intake history.
